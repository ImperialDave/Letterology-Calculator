# StarWords — credits

N64-style textures in this folder (and any canvas-generated 64px tiles) are
original Glyphbound work or CC0 sources downsampled to nearest-neighbor.

Runtime albedos are painted in `src/glyphbound/sortie/tex-paint.ts` and dumped
to `public/glyphbound/sortie/tex/` as 64×64 nearest PNGs (Lambert, no PBR).
Optional CC0 references used as silhouette / albedo noise, recolored:

- Kenney.nl Prototype & Nature kits — CC0, https://kenney.nl
- ambientCG / Poly Haven PBR albedos — CC0, downscaled to 64×64

Lizard fighters are original low-poly code meshes (olive scale, brass membranes).
No Nintendo models, textures, music, or quotes.
