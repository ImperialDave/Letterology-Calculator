## Railway

If Railway says the GitHub repo is not found, it is looking at an old repo id or it was never granted this repository.

1. Open [github.com/apps/railway](https://github.com/apps/railway) → **Configure** / **Install**
2. Grant access to the **ImperialDave** account
3. Repository access: **All repositories**, or add **Letterology-Calculator**
4. In Railway: service → **Settings** → **Source** → disconnect
5. Connect GitHub → **`ImperialDave/Letterology-Calculator`** → branch **`main`** → Deploy

`railway.toml` already sets `npm run build` and `npm start`.
